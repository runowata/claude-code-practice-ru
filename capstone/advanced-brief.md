# Задание: проверять каждый pull request, в заданных пределах

**От:** руководителя команды

Мы хотим, чтобы Claude проверял наши pull request в CI одинаково на любой машине и чтобы ничто из запускаемого им не работало без ограничений. Постройте это в данном репозитории и закоммитьте всё: команда получит только то, что есть в git.

## Что нам нужно

1. **Две задачи одновременно.** Выполните части 2 и 3 в двух сессиях Claude Code, работающих одновременно, каждая в своём worktree, и слейте обе ветки в `main`. Worktrees не должны попадать в git. После того как обе сессии закоммитят, пока оба worktree существуют, сохраните вывод `git worktree list --porcelain` в `.practice/a-capstone-worktrees.txt`.
2. **Скрипт проверки.** `scripts/review-staged.sh` отправляет проиндексированные изменения в `claude -p` и сохраняет результат в JSON: инструменты только для чтения, всё остальное отклоняется без запроса разрешения, лимит ходов не больше 10. Запустите его один раз на проиндексированном изменении в одну строку и сохраните результат в `.practice/a-capstone-run.json`.
3. **Наш плагин, для всех.** Marketplace внутри репозитория, `team-marketplace/`, с одним нашим плагином. Закоммиченный `.claude/settings.json` регистрирует его относительным путём и включает плагин, так что никто ничего не устанавливает вручную.
4. **Проверка, которую можно повторить.** Динамический workflow, который проверяет каждый файл в `src/`, а второй агент перепроверяет каждую находку; он сохранён в `.claude/workflows/` и закоммичен.
5. **Проверка в CI с ограничениями.** `.github/workflows/claude-review.yml` проверяет каждый pull request через `anthropics/claude-code-action`: закреплён на теге релиза или полном SHA коммита, учётные данные берутся из секрета репозитория, Claude действует с собственным токеном задания только для чтения, лимит ходов не больше 10, разрешённые инструменты без неограниченного Bash, тайм-аут задания не больше 30 минут. Единственная настройка GitHub — этот секрет, без GitHub App. Claude проверяет, сливает человек.

## Готово, когда

- `npm test` проходит и ничего не осталось незакоммиченным.
- `npm run check -- a-capstone` проходит.
- Затем всё уберите, как сказано на странице итогового проекта в руководстве: удалите workflow проверки, секрет и, для ключа API, сам ключ, чтобы не осталось действующих учётных данных.
